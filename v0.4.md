# v0.4 — UX Refresh + UTM ZC

## Cambios principales

### 1. UX más profesional y guiado
- Se rediseñó la interfaz con una jerarquía visual más clara.
- El flujo de creación ahora está dividido en pasos:
  - contexto
  - clasificación
  - IDs técnicos y creativo
- Se agregaron tarjetas de ayuda, resumen automático y una vista de resultado más clara.

### 2. Historial más fácil de usar
- El historial ahora incluye:
  - métricas rápidas
  - búsqueda
  - filtro de campañas estacionales
  - filtro de plantillas
- La duplicación mantiene un flujo más claro y conserva el comportamiento de `utm_id` incremental.

### 3. Consistencia de naming
- Se unificó el uso de `utm_zc` en la interfaz y la lógica.
- La capa de persistencia mantiene compatibilidad con instalaciones previas que todavía tengan `utm_sc` en la base.

### 4. Compatibilidad con Supabase
- El guardado intenta usar `utm_zc`.
- Si la tabla todavía usa la columna legacy `utm_sc`, hace fallback automáticamente.

# v0.3 — Maestro UTM

## Cambios principales

### 1. Nuevo modelo del maestro UTM
- Se agregaron los campos:
  - `utm_id` autogenerado con formato `MMMYY-#####`
  - `utm_sc`
  - `utm_name`
  - `utm_source`
  - `utm_medium`
  - `utm_intent`
  - `utm_business`
  - `utm_campaign_id`
  - `utm_asset_id`
  - `utm_term`
  - `utm_content`
  - `owner`
  - `utm_created`
- El historial ahora muestra estos campos y permite duplicar registros con un `utm_id` nuevo.

### 2. Reglas de validación
- Todos los campos UTM quedan limitados a 30 caracteres.
- `owner` y `description` quedan sin ese límite.
- Si la campaña es de estacionalidad, `utm_sc` es obligatorio.

### 3. URL generada
- La URL sigue incluyendo los UTMs estándar:
  - `utm_source`
  - `utm_medium`
  - `utm_campaign`
  - `utm_id`
  - `utm_term`
  - `utm_content`
- Además agrega los campos extendidos del maestro:
  - `utm_sc`
  - `utm_name`
  - `utm_intent`
  - `utm_business`
  - `utm_campaign_id`
  - `utm_asset_id`

### 4. Configuración
- La configuración ahora administra catálogos controlados para:
  - `source`
  - `medium`
  - `intent`
  - `business`
  - `zc`

## Migración requerida en Supabase

Ejecutar:

```sql
\i utm_master_migration.sql
```

O copiar el contenido de `utm_master_migration.sql` en el SQL Editor de Supabase.
